The rows that matter are the derived ones. A ratio two operations away from anything anyone filed still names every filed fact it came from, so if the ratio is wrong the wrong input can be located rather than guessed at.

Why the earliest filing wins

The same figure is filed many times

the same figure is reported many times -- in the original 10-K, again as a comparative the next year, again in each quarter's year-to-date column. The earliest FILED entry for a period is used, because a lineage that followed restatements would explain a number using characters from a document published after it.

Failures

FilerRecorded failure
KOFetchError: KO: no usable revenue concept in the cache

A fetch that failed is in the results file as a failure rather than absent from the companies list. A provenance library that quietly drops what it could not retrieve is the one thing it must not be.
